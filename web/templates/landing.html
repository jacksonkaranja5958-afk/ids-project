About

A working IDS, built from scratch

SentinelX started as a first software project and grew into a full intrusion detection system — hash matching, heuristic analysis, a trained machine learning classifier, and a simulated sandbox, wired into a decision engine and a live operations dashboard. Every module is real and tested; where something is simulated (sandbox detonation, hourly traffic history), it's labeled honestly rather than faked.

Features

Four detection layers, one verdict

Each module catches a different class of threat. Together they cover what any single technique misses.

REAL

Hash Matching

SHA-256 fingerprinting against known-malicious hashes. Instant, near-zero false positives.

REAL

Heuristic Analysis

Catches disguised files like invoice.pdf.exe using generic safe-vs-dangerous extension pattern matching.

REAL

ML Phishing Classifier

Random Forest model trained on 30,000 real URLs, 17 lexical features, 99.75% test accuracy.

SIMULATED

Sandbox Detonation

Shannon entropy analysis on file bytes stands in for real isolated execution — documented as such.

REAL

Live Packet Capture

Scapy-based network sniffing shows real traffic metadata on your machine's interface.

REAL

ARP Device Discovery

Live scan of your local subnet, returning real IPs and MAC addresses of connected devices.

How It Works

Request to verdict

01

Input received

A file path or URL is submitted through the dashboard or CLI.

02

Parallel detection

Hash matching, heuristic analysis, and the ML classifier run immediately.

03

Escalation if suspicious

Disguised files are escalated to sandbox entropy analysis for a deeper read.

04

Decision & logging

A verdict — Allow, Block, or Suspicious — is issued and permanently logged.

05

Dashboard visibility

Every decision surfaces across Alerts, Incidents, Reports, and Logs in real time.
